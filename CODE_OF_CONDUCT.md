# Code of Conduct

## Our pledge

We pledge to make participation in awesome-kling a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, level of experience, nationality, personal appearance, race, religion, or sexual identity.

## Our standards

**Positive:** respectful critique, constructive PR review, giving credit to prompt authors, assuming good intent.

**Unacceptable:** harassment, doxxing, posting illegal content, spam, plagiarizing prompts without Source credit, sexual content involving minors (zero tolerance).

## Enforcement

Report issues to the repository maintainer via GitHub issues (private contact if needed). Maintainers may remove content, edit, or ban contributors for violations.
