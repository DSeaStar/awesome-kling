# Kling AI 九大商用玩法

> 面向广告、电商、短视频与品牌团队的可落地工作流。提示词可直接在 [Kling AI](https://kling.ai/) / Kling 3.0 中试用，并按产品图、参考视频做图生视频 / 运动控制微调。

---

## 1. 追热点 - 同款动作复刻

**技巧**：用 Motion Control 或参考视频锁定动作，再替换主体与场景，快速出「同款」热点内容。

**方法**：
1. 下载热点视频关键片段（注意版权）
2. 提取角色/产品图作为主体参考
3. 用 Motion Control 迁移动作
4. 用提示词改写场景、服装与品牌元素

**提示词骨架**：
```
使用参考视频的动作与镜头节奏，将主体替换为图中产品/人物。
保持动作流畅、镜头稳定，环境改为 [新场景]。
品牌色调 [主色]，无 logo 文字。
```

---

## 2. 商业广告 - 运动饮料

**提示词**：
```
为图中运动饮料生成 12 秒高端广告。
[0-3s] 微距：汗水与冰珠在瓶身滑落，侧逆光，浅景深。
[3-7s] 运动员拧开瓶盖痛饮，慢动作水花，城市跑道背景虚化。
[7-10s] 快速剪辑：冲刺、击掌、瓶身旋转 hero shot。
[10-12s] 产品居中定格，干净背景，可叠加 slogan 空间。
节奏明快，商业广告调色，4K，电影感。
```

**特点**：
- 分镜写清时间轴，Kling 3.0 更易遵守结构
- 产品一致性依赖参考图（Image-to-Video / Elements）

---

## 3. 品牌宣传 - 生活方式片

**提示词**：
```
生成一段讲述 [品牌名] 生活方式的 15 秒宣传片。
自然光室内，真实人物，无夸张滤镜。
旁白语气平静、留白多；产品自然出现在生活场景中，不要硬广贴片。
运镜：缓慢推近 + 空镜过渡，日系/北欧简约美学。
```

---

## 4. 穿搭变装 / Lookbook

**提示词**：
```
让图中女生依次换上 @图1 @图2 @图3 三套服装做卡点变装。
每套服装包含：半身走位 + 全身定格展示。
运镜：中景→全身→细节特写，切换干脆。
背景简洁影棚，卡点节奏，竖屏 9:16。
```

---

## 5. 直播带货口播

**提示词**：
```
生成 15 秒带货口播，产品为图中面霜。
人物亲手涂抹在手背，给出近景质地展示；侧脸转头展示瓶身细节。
镜头半身→特写切换 3 次。
口播包含 2 个核心卖点 + 结尾强 CTA。
自动可加字幕空间，节奏紧凑，轻微环境音。
```

---

## 6. 动态海报 / 竖屏卡点

**提示词**：
```
15 秒竖屏 9:16 卡点短片。固定机位，元素按分镜依次显现。
背景音乐卡点，画面干净，适合小红书/抖音首屏。
```

---

## 7. 广告复刻 - 产品替换

**提示词**：
```
模仿【@视频1】的分镜与节奏，将所有产品替换为【@图片1】的无人机。
画面主色蓝黑，旁白与音乐改为介绍无人机性能。
多角度展示机身、螺旋桨、飞行瞬间，保持产品一致性。
```

---

## 8. 真人短剧钩子（竖屏）

**提示词**：
```
【风格】竖屏爽剧，强情绪特写，高饱和。
【时长】10 秒
[0-3s] 女主摔门而出，雨夜街道。
[3-7s] 男主追上抓住手腕，对白口型："你听我说完！"
[7-10s] 女主回头落泪特写，切黑。
雨声环境音，电影打光。
```

---

## 9. AI 漫剧 / 角色一致性

**技巧**：用 Elements / 角色参考固定人物，分镜多镜头保持同一角色。

**提示词**：
```
使用角色参考保持人物五官与服装一致。
分镜 1：教室窗边独白。
分镜 2：走廊追逐。
分镜 3：天台对峙。
动漫电影感，流畅动作，稳定身份。
```

## API / 工作流备注

| 场景 | 推荐能力 |
|------|----------|
| 产品广告 | Image-to-Video + 多镜头时间轴 |
