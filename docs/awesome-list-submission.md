# 提交到 sindresorhus/awesome 的准备清单

目标：把本仓库挂到 [sindresorhus/awesome](https://github.com/sindresorhus/awesome) 生态（需满足其 list 规范）。

## 规范自检

- [x] 有 `Awesome` badge 链到 sindresorhus/awesome  
- [x] MIT 或兼容许可证（本仓 MIT）  
- [x] 中文主页 `README.md` + 英文 `README-en.md`  
- [x] 目录 / TOC  
- [x] 贡献指南 `CONTRIBUTING.md`  
- [x] Code of Conduct  
- [ ] 内容量持续增长（建议 ≥ 数周更新、条目丰富）  
- [ ] 描述简洁、非营销堆砌  
- [ ] 无失效大面积链接  

## 建议等待

star / 外部引用稍有积累后再提 PR，通过率更高。

## PR 时

1. Fork `sindresorhus/awesome`  
2. 在合适分类（如 Media / AI related）按字母序加入：

```markdown
- [Awesome Kling](https://github.com/DSeaStar/awesome-kling) - Kling AI / Kling 3.0 prompts, I2V, Omni workflows, and weekly X crawl.
```

3. 遵守他们的 PR 模板与 CI。
